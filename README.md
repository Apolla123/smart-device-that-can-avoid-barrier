# Разработка умного устройства, способного объезжать препятствия.

**Цель работы** — разработка автономного мобильного устройства на базе Robotic Car Kit ESP32-CAM, способного обнаруживать препятствия, определять расстояние до них, измерять дистанцию и самостоятельно выбирать направление объезда. 

Развитие автономных мобильных роботов актуально для задач объезда помещений, поиска объектов и обеспечения безопасности на охраняемых территориях, так же актуальность проекта в создании недорогих устройств, которые могут перемещаться без постоянного участия человека, анализировать окружающую обстановку и реагировать на препятствия в реальном времени.

Для измерения расстояния применяется ультразвуковой датчик HC-SR04. Датчик формирует ультразвуковой импульс, измеряет время возврата отражённого сигнала и позволяет рассчитать дистанцию до препятствия. Расстояние вычисляется по формуле, запрограммированой производителем: 58. Полученное значение используется в алгоритме для остановки на безопасно расстоянии и развороте. Логика безопасного расстояния реализована следующим образом: если измеренное расстояние до препятствия становится меньше заданного порога, у нас оно равно 25, робот останавливается. 

Базовое движение робота реализуется с помощью драйвера моторов и четырёх колёс, программой на языке C++ в среде Arduino IDE формируются команды для двигателей: движение вперёд, движение назад, поворот влево и поворот вправо.

**Итоговый алгоритм работы устройства включает следующие этапы:**

1. Считывание расстояния до препятствия ультразвуковым датчиком.
2. Сравнение расстояния с безопасным порогом.
3. Остановка робота при опасном приближении.
4. Анализ свободного пространства слева и справа.
5. Выбор направления объезда и формирование команд для моторов.

Для оценки эффективности устройства планируется провести 15 автономных заездов перед препятствиями. В каждом заезде фиксируются: факт обнаружения препятствия, расстояние остановки, выбранное направление объезда, успешность маневра и время прохождения участка. Успешным считается заезд, при котором робот самостоятельно остановился перед препятствием и объехал его без столкновения.

Дополнительно будет оценено влияние освещённости на работу системы. Испытания планируется провести при ярком освещении, умеренном комнатном освещении и в условиях пониженной освещённости. 

**Выводы:** ожидаемым результатом проекта является автономное мобильное устройство, умеющее находить и объезжать препятствия. Устройство должно обеспечивать стабильное движение, корректное измерение дистанции, остановку перед опасным объектом и выбор направления объезда на основе анализа свободного пространства.
